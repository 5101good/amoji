# Amoji 官方表情包

[English](README.en.md)

一套表情包，一位有自己性格的对话搭档。人看图片，AI 读固定文字语义；每个表情实现一个 [Amoji 0.1](../../docs/specs/amoji-0.1-rfc.md) 码位，可以自然地出现在双向交流中。

| 表情包 | 风格与用途 | 数量 |
| --- | --- | --- |
| [经典](classic.amoji) | 奶白圆团，感谢、鼓励与日常协作 | 24 |
| [办公](office.amoji) | 灰蓝纸张，确认、进度与交接 | 24 |
| [慢半拍猫](slow-cat.amoji) | 水彩小猫，放松、思考与陪伴 | 4 |
| [搭把手犬](good-dog.amoji) | 毛绒小狗，回应、鼓励与感谢 | 4 |
| [像素搭档](pixel-pal.amoji) | 像素机器人，专注、排障与小小里程碑 | 4 |
| [灵感水母](orbit-jelly.amoji) | 玻璃水母，探索、联想与坦诚的不确定 | 4 |
| [纸片鹅](paper-goose.amoji) | 剪纸小鹅，幽默、温和提醒与沟通减负 | 4 |

共 7 套、68 个表情。经典与办公各 24 个表情，实现相同的 22 个码位，各自是独立完整包；五套角色包共 20 个表情。

经典与办公随插件内置；其他包在 dsh 的导入与导出中选择 `.amoji` 文件即可导入，市场支持逐包下载、安装或独立收藏。经典和办公各带 5 条可选效果（协作提示），安装和发送表情不会启用它们；五套角色包是纯表情包。

`catalog.json` 给出下载身份、数量与 SHA-256；同名 `manifest.json` 是可检查的完整语义和素材清单。每个包独立满足市场 10 MiB 上传限制。这里的“官方”指项目制作并分发的内容，不代表社区上传者填写同样署名就获得认证。

固定语义的原文是中文，并提供英文语义：经典与办公的英文为机器翻译后人工审核，五套角色包的英文为机器翻译，均在清单中标明。素材、语义和生成提示按 [CC0-1.0](LICENSE) 提供。经典/办公的生成提示与来源见 `generation.classic-office.json` 和 `provenance.classic-office.json`；角色素材由 Codex 内置 imagegen 逐张生成，提示与参考关系见 `generation.json`，来源摘要与编码过程见 `provenance.json`。`images/` 保存随项目分发的透明 WebP 成品。

维护者运行 `npm run build && node scripts/build-official-packs.mjs` 可从已有成品重新封装；不调用模型。制作新素材时可传入仅本地使用的源图目录，按 `<pack>/<expression>.png` 组织。脚本检查透明通道，标准化为 512px，验证完整包并生成确定性 ZIP。修改已发布内容必须递增版本并产生新发布身份，不能覆盖旧版本。

仓库包、本地预览和生产市场是不同交付环节：本地预览加载这七套包；GitHub Release 构建会附带七套下载制品；生产市场仍须通过上传、独立审核和公开流程发布，构建不会写入线上数据库或绕过审核。
