# Claude Desktop Mods 产品适配

本轮基于 main f871c56，在独立 worktree 实施。用户已授权持续开发与验证，要求未来可复用到 Codex；另一个任务的市场功能不在范围内。

## 产品约定

Claude Desktop Code 的 AbovePrompt 入口打开原生 Pane。人选图直接发送固定文字语义，AI 通过 search/emit 工具选取受策略约束的表达。消息中的短标记只引用当前会话持久化的不可变消息；未知、伪造或跨会话标记保持原文。图片只用于界面，不进入模型上下文。

面板支持双画风、搜索与分页、个人库（归档/恢复、版本）、创建（图片、一个意图输入框、当前会话模型默认且可选择、AI 建议可编辑、明确核对后确认）、草稿恢复、包导入导出、AI 风格/频率/暂停、中英界面。创建固定语义后通过新版本修订，历史不改。错误不能清空草稿或隐式重复提交。

## 分层

1. 现有领域与共享服务：SQLite、不可变 revision、策略、租约和文件校验保持单一来源。新增显式 session-only capability，只有人工接收和历史读取允许没有 turnId；AI search/emit 仍要求真实回合。
2. src/application：宿主无关的表情交互用例与 DTO。接收受信任的会话绑定，通过 SharedClient 公共接口，不接触 Claude 的事件、控件、标记、模型 SDK 或 dsh 类型。UI 不得直接写 SQLite。
3. src/claude-mods 与 plugins/amoji-claude-mods：前者 Node 桥接本地 IO/缩略图/宿主消息编码，后者公开 Mods API 事件与原生界面。stdin JSON 单次进程通信，无 shell 拼接，模型工具不暴露任意文件路径、管理写操作和 session/turn 参数。

## 可靠性与边界

- 真实 session.id、turn.start、session.turns 由宿主读取；拒绝子代理继承主回合。
- receive 按请求 ID 幂等。发送进程先准备持久消息再提交；提交结果未知禁止自动重试，界面明确提示，用户可决定重新发送。重复点击锁定。
- 仅完整匹配同会话、同方向持久消息标记才重绘，不按模型自报资产查图。保留标记前后正常文字，历史使用已存 revision，不跟随个人画风重写。
- 缩略图采用已有 poster，分页并限制单图大小；原图不进入 Mods tree。动画使用静态预览并明确说明。
- Mods 无公开文件选择器，使用明确的本地路径输入；只在人操作触发的导入/导出流程读写，导出拒绝覆盖已有文件。
- UI 跟随公开 settings.language（中文/英文），无可读配置时默认中文。原生 Desktop 应用语言未通过公开 API 提供时不声称自动读取。
- AI 建议使用 $.model.complete，只有意图和固定指令，没有图片、会话历史、工具；不改当前对话模型。最长 45 秒，1200 tokens，无自动重试，取消和过期响应不覆盖编辑。
- 不修改全局模型、其他插件、原目录和他人工作树。不自动发布/合并。真机验证优先 Haiku 低成本模型。

## 验收

自动化覆盖会话隔离、伪造/重复标记、未知提交、偏好策略、草稿/版本/导入导出、缩略图预算、纯文本模型工具结果；原生插件 validate/test；完整 Node 回归和 dsh 回归。实际 Desktop 验证点击发送、模型工具选择表情、双向图像重绘、管理与设置。记录测试、安装、原生观察与真实推理四种证据，不能相互替代。
