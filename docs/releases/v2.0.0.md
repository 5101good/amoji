# Amoji 2.0.0

Amoji 2.0.0 将 dsh 与 Claude Desktop Code 本地会话统一到 **Amoji 0.1 协议**：人看图，AI 读固定语义；AI 按码位表达，宿主按用户首选表情包配图。这是与 1.x 不兼容的主要版本升级。

## 本次变化

- 采用 33 个核心码位的注册表、多语言固定语义与翻译来源；支持用户附言、AI 工作时的纠偏信号与中断、决策选项和快捷回复。表情与选择只表达沟通意图，不是授权或任务完成证明。
- dsh 与 Claude Mods 提供双向表情、个人库、草稿预览确认、不可变版本、导入导出、AI 偏好和文字建议。Claude Mods 同时提供市场浏览与安装、账号连接、分享投稿及可选协作提示。
- 七套官方包共 68 个表情。经典与办公各 24 个，并随插件内置；慢半拍猫、搭把手犬、像素搭档、灵感水母、纸片鹅各 4 个，作为独立包分发。
- 五套角色包的全部 20 条英文经机器翻译、AI 预审和维护者逐项人工审校，记录为 `machine-reviewed`，包版本升至 `2`；没有把机器翻译标为纯人工翻译。[审校记录](https://github.com/5101good/amoji/blob/v2.0.0/docs/releases/v2.0.0-english-review.md)保留范围与确认依据。
- 修复 dsh 新会话输入框居中时表情弹窗过矮的问题，为图片网格保留可用空间。
- 更新受影响依赖以修复已知安全问题；根项目与市场项目的依赖审计均报告 0 个漏洞。dsh 宿主和 SDK 基线保持不变。

## 安装

需要 **Node.js 24+**。dsh 基线为 **0.1.5-rc.2**；Claude Mods 面向支持 Mods 的 **Claude Desktop → Code → 本地会话**，Claude Code 基线为 **2.1.295+**。普通 Chat、Cowork 与云端会话不在 Claude 适配范围。

从本次 Release 下载附件并使用同次 `SHA256SUMS` 核对。dsh 的新 profile 可按以下步骤初始化、安装并启动：

```sh
npx @deepseek-ai/dsh@0.1.5-rc.2 --profile amoji --from-default-profile web --help
npx @deepseek-ai/dsh@0.1.5-rc.2 plugin --profile amoji add ./amoji-dsh-2.0.0.tgz --ignore-scripts
npx @deepseek-ai/dsh@0.1.5-rc.2 --profile amoji
```

使用已有 profile 时替换名称，先保存工作并退出，安装后重启。Claude 用户解压 `amoji-claude-mods-2.0.0.zip`，保留 `.claude-plugin/` 与 `plugin/` 完整目录，在解压目录执行前两条，再进入使用 Amoji 的项目目录执行第三条：

```sh
npm ci --prefix ./plugin/runtime --omit=dev --ignore-scripts
claude plugin marketplace add .
claude plugin install amoji@amoji-desktop --scope local
```

重开本地 Code 会话或运行 `/reload-plugins`。安装需要网络获取锁定依赖；附件不捆绑 Node、宿主、用户数据、凭据或原生二进制。完整步骤见 [dsh 安装指南](https://github.com/5101good/amoji/blob/v2.0.0/docs/dsh-installation.md)与 [Claude Mods 指南](https://github.com/5101good/amoji/blob/v2.0.0/plugins/amoji-claude-mods/README.md)。

## 兼容与数据

| 对象 | 版本 |
| --- | --- |
| 产品、dsh 包、Claude Mods 包 | `2.0.0` |
| 协议与 `.amoji` 格式 | `0.1` |
| 码位注册表 | `0.1-r3` |
| 本地共享 API | `3` |
| 本地数据库 Schema | `1` |

这些版本分别维护。新的 Amoji 0.1 格式取代此前的表情包与场景包格式；**1.x 导出的 `.amoji` 包不能导入，旧库内容不会自动迁移**。

2.0.0 在原数据目录使用新的 `library-0.1.sqlite`，保留旧 `library.sqlite`，并继续使用 `blobs/`。不要求创建空目录；如需隔离试用，可用 `AMOJI_DATA_DIR` 指定另一目录。升级前保存工作，关闭所有旧客户端、等待共享服务退出并备份完整目录。新库初始化内置经典与办公包；dsh 与 Claude Mods 共享新库时应同时使用 2.0.0。不要手改数据库版本号、替换数据库文件名或删除旧库。回退前停止新版服务，再恢复旧版程序使用保留的旧库；新库内容不会自动回写旧库。

市场服务另需执行 `0010-amoji-0.1.sql` 并发布兼容包；**插件发布、仓库官方包与生产市场上架是分别验证的步骤**。本说明不将 GitHub 附件发布视为市场部署完成。安装、收藏和 AI 发送不会启用效果；一次性提示与会话规则都需用户明确选择，不执行作者脚本，不增加工具权限，也不保证模型遵从。

## 验证与限制

候选的核心、dsh、Claude 控件、Claude 制品、发布脚本和官方包自动检查已通过。最终标签对应的远端工作流、附件下载核对、真机 UI、真实模型回合和生产市场状态分别记录；历史验收结果不能替代本次最终发行包验收。构建身份见 `BUILD_PROVENANCE.json`，附件摘要见 `SHA256SUMS`，许可见 `LICENSE`、`NOTICE` 与 `THIRD_PARTY.json`。

- dsh 对宿主待决确认的识别仍有限，pressure-sensitive 码位只在 `core:decide` 之后受到待决确认限制；RFC 自适应频率尚未实现，使用每次回应的固定上限。
- 协议支持文字锚定，dsh 尚未提供从原文选择锚点的菜单。
- Linux、Windows、其他宿主版本及全部模型组合没有完整真机矩阵；Code Dispatch / PTC 嵌套工具不保证图片展示。
- Claude Mods 文件输入使用本地路径，动画显示静态封面。模型建议可能收费；超时、取消、配额与格式错误不会自动重试。
- 独立真人易用性研究未作为已完成项。旧 Codex/Claude hook 适配器仍为 legacy。

代码与技术文档为 MIT；官方素材、固定语义与生成提示为 CC0-1.0，第三方依赖保持各自许可。

## English

Amoji 2.0.0 brings dsh and local Claude Desktop Code sessions onto the **Amoji 0.1 protocol**: people see artwork, AI reads fixed meanings, and the host chooses artwork for an act from the person's preferred packs. This is a breaking major upgrade from 1.x.

### Changes

- A registry of 33 core acts, multilingual fixed meanings and translation provenance, user notes, correction signals and interrupts while AI works, decision options and quick replies. Expressions and choices communicate intent; they do not grant permission or prove completion.
- Both adapters provide two-way expressions, a personal library, draft preview and confirmation, immutable revisions, pack transfer, AI preferences and wording suggestions. Claude Mods also includes marketplace browsing and installation, account pairing, publishing and optional collaboration guidance.
- Seven official packs contain 68 expressions. Classic and Office have 24 each and ship with the plugins; Slow Cat, Good Dog, Pixel Pal, Orbit Jelly and Paper Goose have four each and are distributed as separate packs.
- All 20 English meanings in the five character packs were machine-translated, pre-reviewed by AI, then individually reviewed and confirmed by the maintainer. They are labeled `machine-reviewed`, with pack versions raised to `2`, not represented as translations authored entirely by a person. See the [review record](https://github.com/5101good/amoji/blob/v2.0.0/docs/releases/v2.0.0-english-review.md).
- Fixed a cramped picker above the centered dsh composer in new conversations, preserving usable room for expression images.
- Affected dependencies were updated for known security issues. Both the root and marketplace dependency audits reported zero vulnerabilities; the dsh host and SDK baseline is unchanged.

### Installation and compatibility

Requires **Node.js 24+**. dsh targets **0.1.5-rc.2**. Claude Mods targets **local sessions in Claude Desktop’s Code tab**, with Mods-capable Claude Code **2.1.295+**; ordinary Chat, Cowork and cloud sessions are outside its scope.

Verify `amoji-dsh-2.0.0.tgz` or `amoji-claude-mods-2.0.0.zip` against this Release's `SHA256SUMS`, then use the commands above and restart the host. For Claude, run the first two commands in the extracted directory and the install command from the intended project. Dependencies are downloaded during installation; archives do not bundle Node, the host, user data, credentials or native binaries. See the [dsh guide](https://github.com/5101good/amoji/blob/v2.0.0/docs/dsh-installation.en.md) and [Claude Mods guide](https://github.com/5101good/amoji/blob/v2.0.0/plugins/amoji-claude-mods/README.en.md).

Product `2.0.0`, protocol `0.1`, registry `0.1-r3`, shared API `3` and database schema `1` are independent versions. The redefined Amoji 0.1 format replaces previous expression and scenario-pack formats: **1.x `.amoji` exports cannot be imported and old library content is not automatically migrated**.

Version 2.0.0 uses a new `library-0.1.sqlite` in the existing data directory, preserving the old `library.sqlite` and continuing to use `blobs/`. An empty directory is not required; use `AMOJI_DATA_DIR` for an isolated trial if desired. Before upgrading, save work, close all old clients, wait for the service to exit and back up the complete directory. The new library initializes Classic and Office; dsh and Claude Mods sharing it should both use 2.0.0. Never edit schema numbers, rename database files or delete the old library. Stop the new service before rolling back to the old program and preserved old library; new content is not copied back automatically.

The marketplace service separately needs migration `0010-amoji-0.1.sql` and compatible pack publication. **Plugin releases, repository packs and production marketplace availability are verified separately**; publishing GitHub assets does not establish production deployment. Installing, collecting and AI sends never enable effects. One-time guidance and conversation rules require explicit choices, run no creator scripts, grant no permissions and cannot guarantee model compliance.

### Validation and limitations

Candidate checks for the core, dsh, Claude controls, Claude archives, release scripts and official packs passed. The final tag’s remote workflow, downloaded archives, live interfaces, real model turns and production marketplace status are recorded separately; historical acceptance does not establish acceptance of this final archive. Build identity is in `BUILD_PROVENANCE.json`, digests in `SHA256SUMS`, and licenses in `LICENSE`, `NOTICE` and `THIRD_PARTY.json`.

Known limits include dsh’s partial pending-confirmation detection after `core:decide`, a fixed per-response expression cap rather than adaptive frequency, and no dsh menu for choosing an anchor from message text. Linux, Windows, other host versions and all model combinations lack a complete live matrix. Nested Code Dispatch / PTC image rendering is not guaranteed. Claude Mods uses local file paths and static animation covers. Suggestions may incur model charges and do not retry timeouts, cancellations, quota or format failures automatically. Independent human usability research is not claimed as complete; old Codex/Claude hook adapters remain legacy.

Code and technical documentation are MIT. Official artwork, fixed meanings and generation prompts are CC0-1.0; dependencies retain their own licenses.
