# 三套协作场景包

[English](README.en.md)

三个正式内容包复用基础库已确认的 10 个固定语义，经典和办公各一套，共 20 个资产/版本。原始语义语言为中文；英文说明和示例帮助理解，不会重写固定语义。切换画风不改变语义或动作，也不会启用动作。

| 场景包 | 内容 | 可选动作 |
| --- | --- | --- |
| [把话说明白](make-it-clear.amoji) | 没看懂、说具体些、举个例子、需要你确认 | 换一种简单说法、先给具体示例；当前会话先结论后依据 |
| [一起把事做好](work-well-together.amoji) | 卡在哪里、正在核对、我来处理 | 说明证据与未知；当前会话完成时说明依据和未知 |
| [轻松一点合作](collaborate-comfortably.amoji) | 辛苦了、不客气、暂时没把握 | 无；纯表达无需动作 |

每个清单都有明确标为“示例”的人→AI 与 AI→人场景，不代表真实模型效果或用户研究。AI 选择和发送表情不会激活动作。

在 dsh 表情管理中导入 `.amoji`，或在公开市场获得独立审核的版本。仓库文件存在不代表已公开；市场发布分配独立包/发布身份。本目录 `.amoji` 是完整 `0.2` 包；同名 `.expressions.amoji` 是兼容 `0.1` 的纯表达包，移除全部动作和绑定，保留精确表情版本、许可和素材。

含动作的表情可选“仅发送”或“发送并应用”。一次性提示仅用于对应输入的一个回合。持续规则在当前会话单独启用，可逐项关闭或关闭全部规则。关闭停止后续应用，不删除已读历史，也不保证模型忘记。安装、收藏、切换画风、AI 发送和新会话均不自动授权。动作是协作提示，不是强制控制，不提升权限、不追加独立推理。

所有复用视觉与固定语义遵循 [基础库 CC0-1.0](../base-library/LICENSE)，来源和原始摘要见 [provenance.json](../base-library/provenance.json)。本目录说明、动作及示例亦使用 CC0-1.0。原始表情对象及 blob 原样保留，未新增生成图片；自动化核验保证与基础库逐项相等。

维护者运行 `npm run build && node scripts/build-seed-scenarios.mjs` 重建；脚本无模型调用，通过真实包校验器执行市场大小、媒体、完整性检查。新内容创建新身份/版本，不能覆盖已发布版本。参阅[开发说明](../../docs/development.md)和[协议](../../docs/specs/scenario-packs-v0.2.md)。
