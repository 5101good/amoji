# Amoji 基础表情库

[English](README.en.md)

`base.amoji` 是普通 Amoji Schema `0.1` ZIP 包。当前经典（`classic`）和办公（`office`）各覆盖相同的 **24 个固定语义**，合计 **48 个资产/版本、49 个素材 blob**（含动画独立静态封面）。新库每次展示当前画风的24项，个人内容另计。

经典延续原创奶白圆团角色，办公采用灰蓝纸张角色。两套画风的同名表达具有相同固定语义；AI 读取文字，不识别图片。切换画风不改写旧消息所引用的精确版本。

- `manifest.json`：与 ZIP 内一致的完整版本、语义、许可及素材摘要。
- `definitions.json`：创作定义；`generation.json`：生成提示记录。
- `provenance.json`：生成器、视觉意图、素材来源和摘要；不是完整生成会话。
- `builtin-policy.json`：包身份与旧默认条目的精确迁移策略。

原创视觉由 Codex 内置 imagegen 为项目制作，来源记录中注明参考和处理方式。目录原创视觉、固定语义及提示使用 [CC0-1.0](LICENSE)；来源记录不保证输出独有性或第三方权利。用户导入素材保留其自身许可。

升级仅按政策归档精确匹配的旧默认引用，保留历史版本、图片、消息和个人内容；同一包身份的迁移不会在每次启动时覆盖用户主动归档/恢复。发布修改内容时分配新包身份，不能复用旧包身份覆盖不可变版本。

构建插件直接复制已审阅的基础包，不重新生成图片。维护者先运行 `npm run build`，再使用 `node scripts/build-collaboration-library.mjs <source-directory>` 从已生成素材封装双画风包；输入目录按 `classic/<slug>.png` 和 `office/<slug>.png` 提供 `definitions.json` 中全部条目的源图。该脚本不调用模型，保留原鼓励动画并使用正式导入校验器验证结果。原始制作目录不随发行包提供；普通安装无需重建资产。更新素材需同步清单、摘要、来源和迁移策略，并执行素材/导入回归验证。
