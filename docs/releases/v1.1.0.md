# Amoji 1.1.0

场景包市场与可选协作动作，并首次随发行提供 Claude Desktop Mods 包。需要 Node.js ≥24；dsh 包需要 dsh 0.1.5-rc.2。

- 在 [Amoji 市场](https://amoji.ai-web.ai) 浏览经审核的精确发布版本，在 dsh 的「表情 → 市场」安装。三套初始包分别用于说清楚、高效协作和舒服地合作。
- 安装、发送表情与启用动作是独立选择。一次性提示只作用于对应回合；两种预定义规则只作用于当前会话，随时可关闭，不执行作者脚本，不保证模型遵从。
- 创作者可投稿，审核者可退回和批准；举报及安全下架会使客户端在获知撤销后停用相关动作。离线状态可能滞后。
- 传统 0.1 表情包仍可导入导出；动作包使用 0.2。本地共享 API 为 2，数据库升级到 5。升级会创建一致性备份；回退须停止所有写入并恢复升级前备份，禁止旧程序直接打开 DB5 或手改版本号。

下载 `amoji-dsh-1.1.0.tgz` 并核对同次发行的 `SHA256SUMS`：

```sh
npx @deepseek-ai/dsh@0.1.5-rc.2 --profile amoji --from-default-profile web --help
npx @deepseek-ai/dsh@0.1.5-rc.2 plugin --profile amoji add ./amoji-dsh-1.1.0.tgz --ignore-scripts
npx @deepseek-ai/dsh@0.1.5-rc.2 --profile amoji
```

安装后重启宿主。包不嵌入 Node、dsh、用户数据或凭据，安装仍需解析依赖。源码、构建提交、依赖许可及附件摘要分别见 GitHub Actions、`BUILD_PROVENANCE.json`、`THIRD_PARTY.json` 和 `SHA256SUMS`。公网服务可用性不等于宿主插件市场收录。

### Claude Desktop Mods

`amoji-claude-mods-1.1.0.zip` 用于 Claude Desktop Code 页签的本地会话：输入区 `☺ Amoji` 按钮或 `/amoji` 打开原生表情面板，支持双向图片消息、个人库和 AI 辅助创建。需要支持 Mods 的 Claude Code 2.1.295+；普通 Chat、Cowork 和云端会话不适用，终端只提供纯文字降级。同样用 `SHA256SUMS` 核对后解压，在解压目录执行前两条，再到要使用 Amoji 的项目目录执行第三条：

```sh
npm ci --prefix ./plugin/runtime --omit=dev --ignore-scripts
claude plugin marketplace add .
claude plugin install amoji@amoji-desktop --scope local
```

重开 Code 会话或运行 `/reload-plugins`。Claude 与 dsh 共用本机 Amoji 库，升级到数据库 5 后两边都应使用 1.1.0；场景包市场和协作动作目前只在 dsh 中可用。详见[插件说明](../../plugins/amoji-claude-mods/README.md)。

模型调用可能收费；动作本身不会另起模型调用。尚未完成五位用户与三位创作者的独立真人易用性研究，不宣称已通过该研究。地区网络差异和未测试的宿主版本仍是使用边界。详见[安装说明](../dsh-installation.md)与[运营说明](../marketplace-operations.md)。

## English

Scenario marketplace and optional collaboration actions, plus the first released Claude Desktop Mods package. Requires Node.js ≥24; the dsh package requires dsh 0.1.5-rc.2.

Browse reviewed exact releases at [Amoji](https://amoji.ai-web.ai), then install through Expressions → Marketplace in dsh. Three seed packs support clear explanations, effective teamwork and comfortable collaboration. Installation, expression sending and action activation are separate choices. Turn instructions target one correlated turn; the two predefined rule templates stay within the current conversation and can be disabled. They execute no creator code and cannot guarantee model compliance.

Creators submit content; independent reviewers request revisions or approve it. Reports and safety removals disable affected actions after the client learns of the revocation; offline information can be stale. Legacy 0.1 expression packs remain supported, scenario packs use 0.2, shared API remains 2, and the local database upgrades to 5. Downgrades require stopping writers and restoring the consistent pre-upgrade backup; never open DB5 with an old binary or edit its version number.

Verify `amoji-dsh-1.1.0.tgz` with the accompanying checksums, use the installation commands above, and restart dsh. Dependencies are resolved during installation; the archive contains no Node/dsh runtime, user profile or credentials. GitHub Actions, `BUILD_PROVENANCE.json`, `THIRD_PARTY.json` and `SHA256SUMS` establish source/build/license identity. Public availability does not imply listing in a host plugin marketplace.

### Claude Desktop Mods

`amoji-claude-mods-1.1.0.zip` targets local sessions in the Claude Desktop Code tab: the `☺ Amoji` composer button or `/amoji` opens the native expression panel, with two-way image messages, the personal library and AI-assisted creation. It requires a Mods-capable Claude Code 2.1.295+; regular Chat, Cowork and cloud sessions are not supported, and the terminal offers a text-only fallback. Verify it with the same `SHA256SUMS`, extract it, run the first two commands in the extracted directory and the third in the project where you want Amoji:

```sh
npm ci --prefix ./plugin/runtime --omit=dev --ignore-scripts
claude plugin marketplace add .
claude plugin install amoji@amoji-desktop --scope local
```

Reopen the Code session or run `/reload-plugins`. Claude and dsh share the local Amoji library, so use 1.1.0 for both after the database upgrades to 5. The scenario marketplace and collaboration actions are currently dsh-only. See the [plugin guide](../../plugins/amoji-claude-mods/README.en.md).

Model calls may cost money; actions initiate no independent inference. The five-user and three-creator independent usability study remains unverified. Regional connectivity and untested host versions remain limitations. See [installation](../dsh-installation.en.md) and [operations](../marketplace-operations.en.md).
