# Amoji 0.1 待排期输入

本文收集从 [协议 RFC](../specs/amoji-0.1-rfc.md) 中移出的实施与验证材料，作为后续制定开发计划的输入。**这里没有确定任何范围或周期**；协议规格以 RFC 为准。

来源包括：RFC 第 2 稿的“假设与验证”和“实施计划”两节，以及两轮产品评审的建议。

## 1. 待验证的假设

| # | 假设 | 不成立时的含义 |
| --- | --- | --- |
| A1 | 用表情纠偏（可锚定到具体文字），比打字更快，也更常被使用 | 锚定与纠偏入口的价值不成立 |
| A2 | 表情的画面能降低负面反馈的心理成本，使用率高于同语义的文字按钮 | 表情的独特价值不成立，需要重新考虑产品定位 |
| A3 | AI 发的表情（包括关系类）被用户接受，而不是被关闭 | AI 方向的默认值和频率需要调整 |
| A4 | 长任务中，不打断回合的纠偏信号能减少整轮返工 | `backchannel` 的价值不成立 |

## 2. 实验设计建议

- **对象**：经常需要纠正 AI 的编程用户，约 20–30 人，至少覆盖中文和英文两种界面语言。
- **方式**：两周**交叉试用**，三种条件轮换：
  1. 自由输入；
  2. 文字快捷按钮；
  3. 图文表情。
- **关系类表情单独评估**：它们不用效率指标衡量。

## 3. 指标建议（门槛为草拟，不是行业基准）

| 指标 | 建议门槛 |
| --- | --- |
| **北极星：纠偏成本与返工量** | 完成一次有效纠偏的中位耗时比自由输入下降 ≥ 20%，返工不增加 |
| 图文相对文字按钮的收益 | 辨认速度、主动复用、表达舒适度至少一项可重复地更好；否则保留文字方案 |
| 新用户无需说明即可选对意图 | ≥ 90% |
| 严重误解、错误控制（误停、误继续） | 零容忍 |
| 第二周主动复用 | 有适用场景时 ≥ 50% 的用户复用 |
| AI 表情被撤回、关闭或被评为打扰的比例 | < 10%，以**整条回复**评估 |
| 模型沉默精确率（不该发时不发） | ≥ 90% |
| `backchannel` 送达率、转为消息的比例、排队时长 | 记录基线 |
| 各码位的使用次数与方向分布 | 作为码位冻结或删减的依据 |

不使用发送次数、安装量或表情包数量作为成功指标。

## 4. 首发范围候选（评审建议，待定）

- **宿主**：先做一个桌面宿主（dsh），聚焦 AI 编程。
- **入口**：约 8 个纠偏入口，即没看懂、不是这个意思、说具体些、举个例子、方向不对、说重点、进展如何、可能有问题。默认显示 4 个，其余折叠。
- **锚定**：先做整条消息锚定，精确到文字的锚定可以后做。
- **素材**：一套官方静态图；用户可以切换为纯文字显示。
- **可能后做**：精确文字锚定、`interrupt` 以外的实时能力、创作者市场、跨宿主换图、扩展码位。

## 5. 代码改造清单

1. **注册表与 Schema**：`src/packs.ts`、`src/drafts.ts`、`src/sample-catalog.ts`、`src/actions.ts`。
2. **存储**：`src/library-store.ts`。
   - 数据库版本重置；
   - 消息增加 `act`、`note`、`glyph_policy`、`anchor`、`registry_revision`、决策选项和操作记录；
   - 语义改为多语言映射。
3. **投影与工具**：`src/projection.ts`、`src/search.ts`（改为多语言分词）、`src/mcp-server.ts`、`src/claude-mcp-server.ts`。实现 `amoji_express`、能力卡、拒绝原因码和语言回退链。
4. **效果（可选模块）**：`src/conversation-envelope.ts`、`src/collaboration.ts`、`src/conversation-rules.ts`。内置模板提示改为按语言提供，“应用效果”改为独立入口。
5. **宿主**：`src/dsh/*` 和 `src/claude-mods/*`，分别确定目标兼容等级。
6. **内容**：重建 `assets/base-library`、`assets/official-packs`、`assets/scenario-packs`。
   - 按 RFC 附录 B 补齐 `realizes` 与 `intensity`；
   - 合并现有 `definitions.en.json`，补齐全部官方表情的 `en` 语义；
   - 为尚无官方字形的码位补画，优先画不含文字的版本。
7. **市场**：`apps/marketplace` 的校验链、按语言筛选、效果明示，以及线上数据重置。
8. **文档**：`docs/architecture.md`、`docs/usage.md` 及英文版；RFC 英文版。
9. **删除旧协议**：`docs/specs/amoji-v0.1.schema.json`、`docs/specs/amoji-v0.2.schema.json`、`docs/specs/scenario-packs-v0.2.md`、`docs/specs/examples/expression.example.json`，以及数据库 4→5 迁移逻辑。删除须与上述实现放在同一变更中。
10. **新增**：`docs/specs/amoji-0.1.schema.json`、有效与失败示例、宿主兼容性测试套件、模型评估集。
