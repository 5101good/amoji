# 表情点选发送与双画风

用户要求：dsh 输入框入口与原生控件高度协调；点选表情直接发送；默认统一到原三款奶白角色画风，另提供严肃、简洁、办公画风可选。

## 行为
- 入口只覆盖自身尺寸，与宿主 28px 工具栏按钮协调；管理界面的控件触控尺寸保持。
- 表情主按钮点选即提交并在 accepted/observed 后关闭；独立详情入口可检查语义。同步发送锁阻止快速双击、同一请求 id 用于不确定结果核对或允许的原请求重试。不可因切会话而投到新会话。
- 默认经典，办公可直接在选择器切换并持久化到共享库。画风与 AI 语气风格是不同维度。设置采用版本 CAS，旧客户端缺省 appearance 时保留当前值。
- 两套素材按语义一一对应，不把两种画风同时放在默认列表。14 个协作语义不变，补回原有“挠头苦笑”“给你加油”两个不同语义，共 16 个。经典保留原三款视觉（庆祝、挠头、鼓励），其余匹配该角色生成；办公全新生成。
- 新素材使用新 asset/revision 身份，历史 resolve 不变。画风切换只影响后续候选，不使已选 token 失效。
- 新包升级只归档精确旧内置默认引用，以及明确列入策略的三款开发样本默认引用（这些样本可能曾被标记 imported）。用户改版、复制、外部导入均保留。归档不删除版本或 blobs，可恢复。

## 数据契约
- PersonalPreferences 新增可选 appearance: 'classic' | 'office'，读取默认 classic；持久化 CAS 写入。忽略缺省值会重置偏好的实现不合格。
- 各新内置 expression.tags 含 amoji:appearance:classic 或 amoji:appearance:office，以及 amoji:family:<slug>。name 与 semantics 在同 family 的两画风中完全一致。
- theme 过滤只作用于 builtin 来源，不能因为任意外部包或本地副本的 tags 被误隐藏。管理界面可按画风查看，归档仍可查。
- LibraryStore.list/catalog/search 只提供偏好画风；emit/receive 的可发资格依据所有未归档精确引用，不因切换画风而拒绝在途请求。
- builtin-policy.json 新增 retired_samples: ExpressionRef[]。该字段只允许固定三个开发 asset id 的原 revision，非法策略拒绝。retired 继续仅处理 builtin 来源。

## 验收
单次点击提交、快速双击只提交一次、不确定投递保留身份、键盘及详情不误发；设置重启持久化、CAS 冲突、旧客户端不重置画风；列表和 AI 候选去重，切换不改历史或在途 token；迁移保留个人条目与历史。素材是真透明，新增素材独立生成，显示尺寸统一（选择器 76px、消息 152px）。31 个静态主素材为 512×512；经典“给你加油”保留原 887×887 动画及 poster 原字节。真实 Edge 查看按钮尺寸、双画风、详情和点选发送（必要时仅 Flash 小额模型验证）。
