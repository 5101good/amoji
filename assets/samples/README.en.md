# Historical development samples

[中文](README.md)

This directory preserves original early development/test artwork created for Amoji with Codex imagegen and fixed protocol fixtures. It is not the current default library; the current 24 meanings and 48 assets across two appearances are in `assets/base-library/`. The dsh distribution excludes this directory.

Original sample artwork and related original text are now provided under [CC0-1.0](LICENSE). `manifest.json` retains historical `rights` wording, including “distribution license pending,” for immutable-revision and fixture compatibility. That historical field does not mean the directory's current distribution license remains undecided. Generation records also retain their original development status; old hashes and protocol fixtures are not rewritten. See `generation.json` for provenance. Licensing does not guarantee exclusive output or third-party rights.
