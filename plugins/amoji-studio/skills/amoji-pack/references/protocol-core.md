# Amoji 0.1 — core rules for pack authors

This file condenses the parts of the Amoji 0.1 protocol that a pack author needs. The full RFC lives at `docs/specs/amoji-0.1-rfc.md` in the Amoji repository. `registry.json` beside this file is the machine-readable act registry, and the build script reads it directly.

The protocol is **experimental**: acts are `provisional` and may still change. If the script says an act does not exist, trust the script.

## Principles that affect authors

| Principle | What it means for you |
| --- | --- |
| Picture and meaning are separate | The AI never looks at the image. Everything it should understand must be in the text semantics |
| An expression counts as a sentence | Sending an expression has the same force as the sender saying its meaning. Its `expects` comes from the act, not from you |
| Narrow only, never widen | No expression approves actions, grants permission or replaces a host confirmation |
| Frozen once sent | Published revisions are immutable. Every change creates a new revision |
| Honest | AI-sent expressions show a communicative stance, not inner emotions |
| Language neutral | Ids are ASCII; every human-facing or model-facing text is a per-language map |

## Acts

Each act has a `family` and allowed directions: `h2a` (person → AI) and `a2h` (AI → person). Each direction has an `expects` value, which is the response it asks for. Run `amoji_pack.py acts --locale <lang>` for the live list.

| Family | Purpose | Acts |
| --- | --- | --- |
| grounding | Did we understand each other? | ack, clarify, elaborate, not-what-i-meant, misread |
| steering | Direction and pace | continue, hold, stop, redirect, to-the-point, stepwise, rest |
| progress | Where the work is | checkin, still-failing, claim, working, blocked, decide, ready |
| epistemic | Judgements | uncertain, idea, concern, affirm, disagree |
| social | Warmth | thanks, welcome, celebrate, encourage, recognize, sorry, oops, company |

Flags, shown by `acts`:
- **R**: the host may execute a pause or stop.
- **G**: the AI should have concrete grounds before sending it.
- **P**: the host blocks the AI from sending it while a confirmation is pending.

Flags belong to the registry. You never set them.

## Source format (`pack.json`)

`init` creates this file. Fill it in; `build` derives every id, hash and timestamp.

```json
{
  "pack_id": "<generated by init; never change it>",
  "slug": "sleepy-otter",
  "version": 1,
  "created_at": "<generated by init>",
  "original_locale": "zh-CN",
  "locales": ["zh-CN", "en"],
  "name": { "zh-CN": "瞌睡水獭", "en": "Sleepy Otter" },
  "description": { "zh-CN": "…", "en": "…" },
  "rights": { "license": "CC0-1.0", "creator": "…", "source": "Generated with <tool>; prompts in prompts.md" },
  "image": { "size": 512, "resample": "lanczos" },
  "expressions": [
    {
      "slug": "lost-me",
      "realizes": "core:clarify",
      "intensity": 2,
      "directions": ["h2a"],
      "image": "images/lost-me.png",
      "text_locale": null,
      "name": { "zh-CN": "没看懂", "en": "Lost me" },
      "semantics": {
        "zh-CN": {
          "meaning": "我还没理解刚才的内容，请换一种更简单的说法。",
          "fallback": "[没看懂]",
          "use_when": ["解释太抽象或跳步时"],
          "avoid_when": ["对方正在道歉时"]
        },
        "en": {
          "meaning": "I haven't understood that yet. Please explain it more simply.",
          "fallback": "[lost me]",
          "use_when": ["When an explanation is too abstract or skips steps"],
          "avoid_when": ["While the other person is apologizing"],
          "translation": { "from": "zh-CN", "method": "machine" }
        }
      },
      "tags": { "zh-CN": ["困惑"], "en": ["confused"] }
    }
  ]
}
```

| Field | Rule |
| --- | --- |
| `slug` (pack and expression) | Lowercase letters, digits and hyphens. Expression slugs are unique and stay stable across versions, because the `asset_id` is derived from `pack_id` + slug |
| `version` | Starts at 1. Increase it for every published change |
| `realizes` | Exactly one registry act |
| `intensity` | `1` light · `2` medium · `3` strong. This is the strength of this picture |
| `directions` | Optional. A non-empty subset of the act's directions that suits this picture; defaults to all of them |
| `image` | Path relative to the source directory. PNG, JPEG or WebP; static only |
| `text_locale` | **Required.** The language of any lettering in the image, or `null` |
| `image.size` / `image.resample` | Output square size (256 · 384 · 512 · 768 · 1024; default 512). Use `nearest` for pixel art |
| `derived_from` | Optional `{pack_id, release_id}` when remixing another pack |

## Limits

Lengths are Unicode code points after NFC normalization; byte limits are UTF-8.

| Field | Limit |
| --- | --- |
| pack `name` / `description` | 60 / 280 per language |
| expression `name` | 40 per language |
| `meaning` / `fallback` | 240 / 80 per language |
| `use_when` / `avoid_when` | at most 4 items each, 64 per item |
| `tags` | at most 8 per language, 32 each |
| name + semantics + tags of one expression | 16 KiB across all languages |
| `rights.license` / `creator` / `source` | 120 / 120 / 500 |
| expressions per pack | 1–200 |
| image | at most 2048 px per side, 10 MiB |
| whole `.amoji` | 10 MiB (market upload limit) |

## Languages

- Tags are BCP 47 (`zh-CN`, `zh-Hant-TW`, `en`, `pt-BR`).
- `locales` lists every language that the pack covers **completely**: every expression has `name` and `semantics` in it, and the pack has `name` and `description` in it. List only what is really complete.
- `original_locale` is the source of truth. Every other language needs `translation.from` and `translation.method`: `human`, `machine` or `machine-reviewed`.
- Write `use_when` / `avoid_when` for each culture; do not translate them literally. A gesture that is friendly in one region can offend in another, and that belongs in that language's `avoid_when`.
- Official packs must cover `zh-CN` and `en`, with human or machine-reviewed translations.
- Hosts never fall back across scripts (for example `zh-Hant` never falls back to `zh-CN`). If Traditional Chinese readers matter, add `zh-Hant` explicitly.
- Prefer art without lettering. Hosts pick text-free or matching-language art for international readers.

## What the build produces

- `asset_id = uuid(pack_id, slug)`. It is stable across versions.
- `revision_id = uuid(expression content)`. It changes whenever any text, setting or art changes.
- `release_id = uuid(manifest)`.
- Art is normalized to a centered square WebP with alpha preserved. Composition is never altered.
- The ZIP is deterministic: the same source gives byte-identical output.

`check` re-verifies any `.amoji`:
- archive layout and CRC;
- that each blob's SHA-256 and size match the manifest;
- that each image decodes to its declared format and dimensions;
- every rule above.
