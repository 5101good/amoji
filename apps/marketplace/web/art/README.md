# 品牌主视觉 / Brand artwork

`expression-future.webp` 是 Amoji 表情市场使用的 AI 生成品牌主视觉，以项目自有的经典「谢谢」表情为参考，采用光学玻璃、液态金属与冷色折射材质。它仅用于品牌展示，不是可下载表情，也不定义或修改表情的固定语义。

`expression-future.webp` is the AI-generated brand artwork used by the Amoji expression marketplace. It reinterprets the project’s original classic “Thank you” character in optical glass, liquid metal and cool refracted light. It is presentation artwork, not a downloadable expression, and does not define or alter fixed expression semantics.
