## 交付目标与执行顺序

1. 修完 08 已知输入与候选失效问题，作为共用管理逻辑前置。
2. **D1 当前 dsh 双向原生接入**：核对实际 npm 包，修正 Host/Client/工具/Connection/会话持久化合同，提供可安装包。在 dsh 输入区直接选择，用户与 AI 表情在会话内展示；模型只收到固定文字。静态、动图、文字回退、页面重载与会话切换必须实际验证。
3. **D2 表情与偏好生命周期**：合并旧 09/12/13/14/16 的共享业务，完成不可变版本编辑、个人副本、归档、偏好和 CAS 冲突；旧消息保留精确版本。管理入口以 dsh 为消费端。
4. **D3 包与基础库**：旧 10/11/18 的完整包导入、导出、新环境恢复及事务校验；集成现有 24 项原创素材，不重新生成。落实内容许可和来源，不包含个人会话/设置/凭据。
5. **D4 dsh 内完整管理界面**：通过已认证 Connection 调用共享业务，在 dsh 页面内完成创建、文字建议、图文预览确认、编辑、副本、归档、设置、导入导出。复用业务实现，不依赖打开独立配套页面；保留可访问性、错误恢复和未保存编辑。
6. **D5 可靠性与交付**：旧 15/17 的断连、超时、重复请求、重连、升级/单端移除数据保留；完成当前 dsh 实际安装和本机 Web 用户旅程，记录模型选择、实际 usage、请求数、图像输入数量及未验限制。最后做整支审查和限定修补。

## 文件责任与接缝

- `src/dsh/contracts.ts`、`host.ts`、`client.tsx`：当前宿主边界；新管理界面拆到 `src/dsh/` 内专责组件，避免把业务复制到前端。
- `adapters/dsh/`、`scripts/build-dsh-plugin.mjs`、`scripts/dsh/`：实际安装包、版本/来源记录、安装与验证辅助。
- `src/library-store.ts` 及共享服务/客户端：唯一数据库写者、版本/归档/偏好/CAS/包事务。需要拆分时沿存储和业务职责组织。
- `src/drafts.ts`、`suggestions.ts`、`media.ts`：沿用已有草稿确认、纯文字建议、真实媒体校验。
- `tests/`：先针对变更补必要失败检查，修复后只运行受影响检查；最终稳定版本统一运行一次完整回归。
- `docs/validation/`：公开实际证据和可复现步骤；`.local/dsh-focus/` 保存测试专用日志、数据和脱敏原始证据，凭据不提交。

| 接缝 | 生产/消费关系 | 执行决定 |
|---|---|---|
| 08→D4 | 纯文字建议、候选有效期 | 先修已知三项，管理复用同一能力 |
| D1→D2/D3/D4 | 当前 Host 身份、RPC 和渲染 | 用实际安装版本作为权威，先完成装载与双向接入 |
| D2→D3/D4/D5 | 不可变 revision、来源、归档、CAS | 导入不能篡改归属，历史始终读固定版本 |
| D3→D4/D5 | 完整包与基础库 | 普通包导入复用相同校验；已存在用户内容不删除 |
| D4→D5 | 用户明确提交、稳定 requestId | 切换/取消与未保存内容保护，未知结果先核对 |
| D1–D5 | 共同修改共享接口与 dsh Client | 串行实现，每阶段单个实现者与一次任务审查 |

每个阶段自洽：D1 验收接入，不声称全部管理已完成；D2/D3 先验证业务合同，D4 验证完整页面行为，D5 汇总真实行为。旧 Codex/Claude 构建和真机验收不作为本轮推进前置；对共用核心的必要兼容回归仍保留。

## 成本与本机状态边界

- 已配置 provider `llm-ai-web` 的 `deepseek-v4-flash` 是本轮测试首选。原用户默认 `gpt-reserve` 不改；测试会话明确选择模型，不静默回退到高价型号。
- 优先不调用模型的 API、组件和页面验证。初始真实验证最多 8 个短回合、每次最多 4 次供应商请求，输出预算按宿主能力限制；失败先诊断，不循环重试。
- 记录 input/output/cache usage；没有网关费率时明确金额未知，不把官方直连价格当用户账单。扩展场景先判断是否有新的验收必要。
- 原 30 场景质量/成本对照仍是完整 v0.1 产品基准，先用 dsh 最小真实旅程证明适配，再按实际消费决定有界执行；不得把本地规则检查称为模型评测。
- 独立 `amoji-qa` profile、专用工作区与 Amoji QA 数据目录用于开发验收，不终止用户已启动的 `web` 服务，不改模型凭据，不处理个人旧会话。最终安装只增添本插件的可回退配置，保留安装前快照。
- 当前版本支持范围如实限定。视觉与语义分离需要观察真实请求/记录，不能只凭模型回答宣称无图像输入。
