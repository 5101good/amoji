# 1.0 发布检查记录

[English](release-audit.en.md) · [文档首页](README.md)

检查日期：2026-09-21。范围为 Amoji dsh 1.0.0；当前真实宿主基线为 dsh 0.1.5-rc.2、macOS arm64、Node 24。此记录不代表其他宿主或模型矩阵已验证。

## 本地验证

- `npm run typecheck` 通过；核心测试 111/111、dsh 测试 95/95、发布检查回归 3/3 通过。
- 国际化测试使用实际已发布的 dsh LocaleRuntime，覆盖语言热切换、字段/无障碍文案、动态状态、错误、输入保留和原生消息词典共存。
- 使用官方 plugin CLI 安装 1.0 候选包，在 Edge 中通过 dsh 设置切换中文→英文→中文。选择器、管理页、创作页、聊天中的表情提示同步更新，未保存文字保留，模型默认仍为当前对话模型。管理页显示 GitHub 项目入口。
- 固定语义及用户输入不因界面语言改变。没有重新调用付费模型、发送测试消息或确认个人草稿入库；先前已成功的 Flash 文字建议流程不作为本轮重新实测结果。
- 发布审计核对实际 tarball、版本、运行入口、基础库、依赖许可、个人路径/凭据特征和 SHA-256。基础库为 24 种语义、48 项视觉资产、49 个 blob。

## 开源检查

- Gitleaks 8.30.1 从官方 Release 获取并校验其 SHA-256；对当时全部 64 次 Git 提交及待发布工作树扫描，未发现匹配规则的泄漏。这是扫描结果，不是不存在任何秘密的保证。报告保留在忽略的本地目录，不上传运行配置或原始日志。
- esbuild 已升级到 0.28.2；官方 npm registry 的完整依赖审计为 0 个已知漏洞。锁文件下载地址统一到官方 npm registry。
- 代码/文档 MIT；基础库和项目生成的开发样本采用各自目录中的 CC0-1.0。旧测试 manifest 的历史 rights 字符串保持不变；开发样本不进入 dsh 分发包。
- tgz 不捆绑 node_modules、原生二进制、个人库或会话。实际构建生成 THIRD_PARTY.json 及第三方许可全文；平台可选依赖仍保留各自许可。
- 当前对外文档中英双语、默认中文。按维护者要求移除旧调研、规划和阶段验收文档，保留运行 Schema、示例 JSON 和测试素材；没有改写已有 Git 历史。
- 已配置安全报告说明、贡献指南、中英 Issue 模板和月度 Dependabot。包元数据及界面入口指向项目仓库。

## 发布与仓库状态

GitHub Actions 为版本标签重新执行测试与打包审计，只发布已验证产物。Release 提供插件包、基础库、许可、SHA256SUMS 和 BUILD_PROVENANCE.json；后者记录提交、标签与 Actions 运行地址。官方 Action 固定提交 SHA，常规验证只有读取权限，发布任务才获得 contents:write。中断的草稿发布可恢复；已发布附件不会被重跑覆盖。

云端执行和下载结果以 [Actions](https://github.com/5101good/amoji/actions) 和 [v1.0.0 Release](https://github.com/5101good/amoji/releases/tag/v1.0.0) 为准。仓库公开操作与发布检查分开确认；本次检查时仓库为私有，GitHub 对该套餐的私有仓库分支保护返回 403。公开后可再启用必需 CI 检查与私密漏洞报告。

已知模型续答和平台限制见[发布范围](release.md)。
