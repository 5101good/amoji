## 01 的完成范围

安装版插件在 Codex Desktop `26.901.41600`、内置引擎 `0.153.4` 完成两个真实任务的三样本双向、明确绑定、配套面板重开、任务卸载后冷恢复及语义回放。44 次实际 Desktop 请求的图像内容块和图像 Data URL 均为0。额外的内置引擎 CLI 矩阵记录28次请求，作为独立补充，不冒充 Desktop 证据。

用户选择沿用 `/amoji → amoji_pick → 配套面板`。这是用户触发的控制入口，返回选中版本的固定语义；三个日常表达工具不接受动态语义或目标会话。该实现选择已写入 Spec 和架构。App 任务 API 仅用于 QA 调度，不是插件运行依赖。

CUA 仍拒绝操作 Codex 主界面，本次视觉证据来自票据明确允许的配套面板；不宣称原生聊天图片渲染或整个 Desktop 应用重启已验证。小样如实保留 `delivery=pending`，已观察的图片有 `presentation=rendered`；完整投递状态机仍在后续范围。

请求观测使用的两次临时非默认 provider 配置均已撤回，配置 SHA-256 与各自操作前一致，两个转发器均已退出。专用测试任务已归档，素材和历史仍保留。证据和入口边界提交：`57e831a`。独立 Spec 复核确认01没有未满足的实质验收项。
