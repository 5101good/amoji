# Amoji · Claude Desktop Mods

[English](README.en.md) · [开源项目](https://github.com/5101good/amoji)

人看图，AI 读固定语义。在 **Claude Desktop 的 Code 页签、本地会话**中，使用原生表情面板、双向图片消息、个人库和 AI 辅助创建。

需要支持 Mods 的 Claude Code（验证基线 2.1.295+）以及 Node.js 24+。普通 Chat、Cowork 和云端会话不属于此适配器。终端提供纯文字降级，图片体验以 Desktop 为准。

## 安装

从 v1.1.0 起，GitHub Release 提供 `amoji-claude-mods-<版本>.zip`，请用同次发行的 `SHA256SUMS` 核对；也可从源码构建。v1.0.0 不含此包。解压后得到 `.claude-plugin/` 和 `plugin/`；保留完整目录。

在解压目录执行：

```sh
npm ci --prefix ./plugin/runtime --omit=dev --ignore-scripts
claude plugin marketplace add .
```

进入需要使用 Amoji 的项目目录，再安装到该项目的个人范围：

```sh
claude plugin install amoji@amoji-desktop --scope local
```

重开 Code 会话，或按宿主提示运行 `/reload-plugins`。Desktop 首次启动会话时可能先显示命令未识别提示，待插件入口出现后用原生按钮打开；不要将它当作普通模型提示反复发送。输入区的 `☺ Amoji` 按钮和 `/amoji` 都可打开面板。若此前安装旧版 `amoji` Claude 原型，请先停用该旧插件，避免同名命令和工具冲突。

依赖按锁文件从 npm 获取，分发 ZIP 不含本机二进制和 node_modules。CLI 与 Desktop 本地会话共用插件设置；从项目范围开始可避免影响其他工作区。

## 使用

- **表情**：按名称或语义搜索，按 Enter 更新结果。在 Desktop 中点击图片即可直接发到当前对话，不必再按发送按钮。名称按钮支持键盘发送；在「管理」中点击名称查看固定语义，终端仍提供发送按钮。右键和拖出图片不会发送。
- **个人库**：查看条目、归档或恢复、为个人条目创建新版本、复制内置表情、选择包版本。历史消息保留发送时的图片与语义。
- **创建**：一个意图输入框，模型默认当前会话模型，可选别名或自定义模型 ID。AI 只读这段文字，无图片或聊天记录；建议需主动采用，再编辑和核对。也可直接手工填写。
- **图片与表情包**：粘贴本地绝对路径（支持 `~/`）。图片支持 PNG、JPEG、WebP、GIF，上限 10 MiB；预览成功并勾选核对才能确认。Claude 显示动画的静态封面。
- **导出**：在个人库选中条目，导出为 `.amoji`。已有文件不会被覆盖。导入检查包结构、哈希、媒体和版本冲突。
- **偏好**：经典/办公画风，AI 语气、频率、暂停。画风影响后续选择，不重写历史。界面中英文跟随 Claude Code `language` 配置，未配置时中文；Desktop 独立应用语言暂未公开给 Mods。

AI 只获得 `search` 和 `emit` 两个表情工具。管理、文件读写和创建确认不会作为模型工具暴露。表情语义是数据，不是任务完成证明、操作授权或需要执行的指令。

## 表情市场与分享

当前源码新增以下能力；已有 v1.1.0 Release 的 Claude ZIP 不包含这些新增入口，需从当前源码构建。

1. 在「管理表情 → 表情市场」搜索和筛选表情包，查看图片、固定语义、作者、许可与可选协作提示。无需登录即可安装整包或单独收藏。下载安装会校验摘要和内容，安装不会启用提示。
2. 已安装内容可离线发送；检查更新时先预览旧、新语义与提示，再明确采用。移除包和取消收藏不会改写历史消息。
3. 在「分享与投稿」连接市场账号，在浏览器核对设备短码后授权，再点击「我已授权，检查连接」。插件不接收账号密码，设备凭据只保存在本机共享服务的私有目录。
4. 可以选择已导入的 0.2 表情包，或在表情库勾选素材后「组织为表情包」，保存并核对图片、固定语义和许可。已保存草稿可以继续编辑。
5. 投稿依次核对介绍、许可、可选提示和完整预览；先上传并校验，再确认拥有公开分发权利，最后投稿等待审核。内容从本机直传 R2。断网保留草稿，未知结果核对原操作；可恢复上传、查看审核意见、撤回待审版本，并创建修订稿。

「协作提示」与固定语义分开：可明确启用至多两条预定义会话规则，同组提示须确认替换；已安装表情的详情还可选择一次性提示后发送。每次提交重新校验精确来源版本，来源下架或移除后停用。只有当前主会话的用户消息会附加提示，不向其他插件、定时任务或子代理传递授权。重启或切换会话需重新启用。

提示通过 Claude 的 `prompt.submit.context` 作为用户文字上下文附加；不执行任意脚本、不增加工具权限，也不保证模型遵从。关闭后后续用户消息会携带空提示快照；已产生的模型回复和历史上下文不能撤销。

## 数据与故障

复用本机 Amoji 库（含 dsh 的库），消息按宿主和会话隔离。可用 `AMOJI_DATA_DIR` 指定测试库，`AMOJI_NODE` 指定 Node 24 可执行文件。不要删除数据库处理兼容问题。

如果共享服务版本较旧，关闭仍使用旧 Amoji 的窗口后重试。遇到“结果未知”先检查会话或库，不要立即重复发送。失败不清空输入；草稿须点击“保存草稿”才持久保存。多个会话编辑同一草稿发生冲突时，可查看最新内容，然后明确采用它，或将自己的文字与图片另存为独立草稿，保留双方修改。

Claude Mods 使用 Node 本地桥接来访问共享服务、生成缩略图及读取你选择的文件。模型建议通过 Claude 已配置的凭据请求所选模型，产生相应文字推理费用；不会单独上传表情图片。界面直接显示位图，不使用 SVG，原始图片完整保留。两套内置画风随包附带显示图片，个人素材使用本地缓存。

## 开发

在仓库根目录：

```sh
npm ci
npm run build:claude
npm ci --prefix .cache/claude-mods/plugin/runtime --omit=dev --ignore-scripts
claude plugin validate .cache/claude-mods/plugin --strict
npm run test:claude
npm run test:claude-artifact
```

修改 `src/claude-mods/native/`，重新构建；`hooks/register.js` 是宿主静态分析所需的单文件生成产物。安装和原生验证步骤见仓库 `docs/claude-mods.md`。

发送后面板保持打开，并提示「已发送 · 等待 Claude 回复」。用户表情在右侧、AI 在左侧显示，不增加角色标签，与 Claude 原生布局一致。需要收起面板时使用宿主右上角的关闭或折叠控件；保留面板可避免当前 Desktop 关闭展开视图后出现空白区域。

当前 Desktop 的原生按钮句柄可能在焦点重绘时过期，宿主日志会记录 `ui_press not handled`。新版入口、导航和操作按钮保留原生外观与键盘能力，鼠标使用稳定 key 的 Client 完整点击事件，交由当前页面的操作映射执行；过期页面和伪造操作不执行。Client 运行失败时退回原生按钮，可使用回车。输入框和下拉菜单仍由宿主处理。参见 [Claude Code #99211](https://github.com/anthropics/claude-code/issues/99211)。

选择器与管理工作区的流程对齐 dsh：快速画风/场景筛选，管理内的创作草稿、AI 偏好及导入导出；创建默认展示语义摘要，按需展开编辑。详见[交互说明](../../docs/claude-mods.md#与-dsh-对齐的使用流程)。
