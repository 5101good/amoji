# Amoji：人与 AI 协作的表情体验

## 目标与授权
用户要求自主重做完整交互、视觉和表情内容，直到产品化发布质量，阻塞项最终报告。此次设计与实现均由代理自行决策，不逐阶段等待批准。范围是 dsh 原生选择器、对话表情、管理界面、协作表情库及实际安装验收；其他端暂停。沿用当前隔离工作树，不覆盖旧历史和用户素材。

## 设计合同
| 项目 | 决策 |
|---|---|
| 核心任务 | 人用一张表情表达协作意图；AI直接读固定文字语义，视觉无需多模态 |
| 主要操作 | 输入区打开表情，按情境浏览，选中后看一句含义，明确发送 |
| 选择器 | 400–440px浮层；标题/关闭和搜索固定，中央列表滚动，底部选中摘要/发送固定；关闭按钮、Esc、点击外部、再次点击入口均可关闭；关闭后焦点合理返回，不丢未知投递身份 |
| 单元 | 图片和名称构成同一个按钮；等大图片框、同高文字行，无重复边框或标签按钮；网格静态封面，播放控制只在大预览/聊天出现 |
| 对话 | 可信关联成功后，纯表情消息显示一张图；固定语义/版本在次级详情。保留真实文字/附件，仅去掉精确匹配的插件语义块。关联未完成显示简短加载，失败保留原消息以免吞内容 |
| 管理 | 上方标题/关闭，左侧导航，右侧内容；库为网格+详情侧栏，不在长列表末尾追加表单。创作基本信息优先，可选细节折叠；导入导出和AI偏好保持独立 |
| 视觉 | 随dsh明暗主题；文本#202329/暗#eff0f3，次文#666d78/暗#aeb4bf，表面#fff/暗#24262c，边线#e4e7ec/暗#40434c，焦点与主动作#4468dc，选中浅蓝/深靛。使用系统中文无衬线，正文14px/1.5，标题18px/600，辅助12px；4/8/12/16/24间距；图片承担性格，周边克制 |
| 状态 | 加载不跳高；空结果有清除入口；失败可重连；未知发送只核对原请求；确认接纳后关闭选择器，不重复发送 |
| 可访问性 | 触控至少36px，关闭40px；可见focus；Escape仅作用于自己的层；键盘完整可达；减少动态偏好；320/390/768/1280宽度与200%缩放不遮挡主要动作 |
| 禁用默认 | JSON常驻、开发术语充当说明、网格套多层卡片、白底素材混搭、把“完成/正在处理”表情当状态证明、无行为的按钮 |
| 参考证据 | 真实旧版dsh截图已观察：底部关闭滚出视口、嵌套标签按钮、白底素材不一致。UIZZE公开页可访问但Slack检索无结果，未获取3–5个有效参考图，记录为参考证据不足，不虚构参考。以宿主现有控件与真实工作流为首要约束 |

## 表情库重组
放弃24项数量目标。优先保留/制作约12–16项明确且不同的协作表达：进度如何、还在吗、卡在哪里、说具体些、举个例子、没看懂、方向不对、先等一下、继续吧、一步一步来、明白了、这个不错、谢谢、一起庆祝。按“进度/澄清/方向/反馈”导航。淘汰调皮、认输、拥抱、寒暄等默认项；作为旧历史版本保留，不删除用户资产。

含义必须明确发送者与接收者。查询/澄清表达可要求解释；“继续吧”只指已经授权工作，不扩大授权；“先等一下”是用户暂停意图，不伪装成已执行控制指令。AI不可仅凭表情声称任务完成、后台持续运行或真实进度，配套事实仍需正文/工具证据。新含义/图产生新revision/asset，不覆盖原固定语义。新安装默认新协作库；已有内置库升级有明确迁移、仅调整项目内置默认，用户导入/个人副本/历史不动。

## 验收
1. 选择器四种关闭、重开、完整键盘、提交未知后关闭重开、切会话均实测/回归。
2. 图片/名称整块点击且统一，长名/动图/失败不破坏布局，列表滚动不遮关闭/发送。
3. 用户/AI历史每个表情只出现一次，无重复固定语义正文；普通混合内容/附件完整保留。
4. 库/编辑/建议/冲突/偏好/导入导出所有可见操作可用，管理开闭保留草稿。
5. 协作表情图文一致、素材风格统一，升级不改历史或个人资产；纯文本模型能正确理解重点场景。
6. 桌面/窄屏/主题/加载失败画面检查，最终实际tgz安装到dsh验证；模型使用Flash限量，默认零模型UI测试。
7. 以可见产品质量作最终判定，测试通过不代替视觉验收。尚未证实的要求不算完成。
