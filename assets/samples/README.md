# 历史开发样本

[English](README.en.md)

本目录保存早期由 Codex imagegen 为 Amoji 制作的原创开发/测试素材，以及固定协议 fixture。它不是当前默认基础库；当前24语义、两画风共48资产位于 `assets/base-library/`。dsh 分发包不包含本目录。

本目录原创样本视觉及相关原创文字现按 [CC0-1.0](LICENSE) 提供。`manifest.json` 中仍保留历史 `rights` 文案（包括当时的 “distribution license pending”），用于不可变版本和测试兼容；该历史字段不代表目录当前分发许可仍待确定。生成记录也保留当时开发状态，不改写旧摘要或协议 fixture。生成来源见 `generation.json`；许可不构成输出独有性或第三方权利保证。
