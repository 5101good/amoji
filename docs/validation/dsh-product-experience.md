## 本轮实现

- 选择器支持入口再次点击、关闭按钮、Escape、外部点击及焦点离开；发送被宿主接纳后收起。未知投递保留原 requestId，不自动另发。
- 图与名称使用同一个选择按钮；可信用户消息仅去除精确插件语义，保留其他文字、附件、引用标签和技能信息。语义/版本折叠查看。
- 表情库与创作导航重做，基础字段优先，高级字段渐进展开；桌面详情分栏、窄屏独立详情。
- 默认库改为 14 张同风格透明 PNG，按进度、澄清、方向、反馈分类；固定语义支持协作意图，不扩大授权、不虚报任务状态。
- 升级仅归档精确匹配的旧 builtin 默认项，保留旧 revision、素材、历史、个人副本和 imported 内容；重启不覆盖用户后来恢复/归档的选择。
- 小高度模式改为两栏选择/语义，中间分别滚动，关闭和发送固定可达。

## 独立审查与剩余项

一次 fresh reviewer 发现 1 个 Important：小高度裁切发送区，主代理在真实 568×320 页面复现，已修复并以实际安装包复验；未发现其他可证实重大问题。

1. **日常入口阻塞**：本轮再次访问 http://127.0.0.1:3080/，应用内浏览器仍返回 ERR_BLOCKED_BY_CLIENT。未绕过，也未把 QA 页面当作日常页面验收。日常 profile 本轮未更新。
2. **浏览器导出落盘未证实**：真实导出返回文件并生成 blob 下载链接；自动触发和直接点击链接的下载事件均超时。选中浏览器的 `downloadMedia` 方法返回成功但无文件路径；Downloads 中唯一同名文件是旧 QA 文件，未冒充本次结果。已去掉“已下载”误导状态，保留可再次点击的下载链接。完整 ZIP 字节/导入导出闭环有自动验证，但不能替代浏览器下载落盘。
3. **200% 缩放未证实**：原生 Cmd+plus 快捷键没有改变浏览器 CSS 视口或 pixelRatio，没有把缩小视口冒充真实浏览器缩放。320/390/568/768/1280 宽度及低高度已实际检查。
4. 尚未合并到 main、推送或公开发布。工作保留在 codex/v0.1-completion。

## 管理写操作补验与修正

- 新建静态表情：选择本项目 PNG → 文字建议 → 独立改名/回退 → 采用 → 保存 → 页面刷新 → 重开草稿 → 保存预览 → 图片可见、勾选后确认 → 库中新增一个 local 条目。
- 新版本：归档/恢复 → 编辑新版本 → 更改名称和固定含义 → 再次预览确认；当前版本变为 v2，旧版本下拉可回看原名称和原义。测试条目最后归档保留，默认可用数恢复为 14。
- 动图：使用测试 WebP 上传，生成独立封面，保存预览，播放/暂停按钮切换成功；保留为具名 QA 草稿，未将不匹配的测试图文发布入库。
- 建议：新增进度、阻碍、澄清、示例、暂停、继续、方向纠偏规则；真实界面“任务完成多少了，请报告真实进度”生成“进度如何”，不再误配庆祝。语义原文保留且仍需用户采用/确认，无模型调用。
- 空草稿：提交被拦截，界面现在直接提示检查“名称”，技术详情折叠；没有以英文 schema 错误充当主要说明。
- 偏好：原值自然/克制/未暂停；用独立 QA SharedClient 制造真实版本冲突，界面保留活泼输入，选择继续编辑后成功保存，再恢复原值。重新连接按钮成功刷新共享库。
- 导入：通过真实文件选择器导入当前14项包，结果新增0/已有14，未改变现有当前版本。
- 焦点：修复关闭详情后在 React 提交前聚焦隐藏列表的问题；390px 页面实际关闭详情后，AX focused element 为原“进度如何”按钮。
- 最终低高度 568×320：关闭按钮高40px、分类按钮高36px、发送按钮高39px，发送下界301px在视口内；截图确认列表与语义两栏可读。
