## 源文件与生成链路

英文可编辑源是 `assets/official-packs/sources/<slug>.json`，不是同名 `manifest.json` 或 `.amoji`。`scripts/build-official-packs.mjs` 从所有源 JSON 和已有图片构造表情、包清单，校验并生成 `.manifest.json`、`.amoji` 以及 `catalog.json`。英文变更会产生新的表情修订和包发布身份；修改的包必须递增整数 `version`，否则脚本拒绝覆盖同版发布。

英文预审阶段未修改版本或生成物；维护者确认后，发布流程将五套角色包整数版本从 1 升到 2，并顺序执行：

```sh
npx tsx scripts/build-official-packs.mjs
npm run test:file -- tests/official-packs.test.ts
```

五套角色包的英文与翻译声明已修订，对应 `.manifest.json`、`.amoji` 及共享 `catalog.json` 已重建；脚本同时检查并写出全部七套官方包。此后若再修订内容，须重新生成不可变修订与发布身份，不能直接修改已发布归档。
