# 05 搜索与完整语义候选

日期：2026-09-16。代码范围 `b3cd64a..2b62375`，实现提交 `6528461`，修补提交 `2b62375`。状态：实现及本地公共合同检查完成，两轴审查通过；真实安装版 Codex 的语境自主选择和无匹配文字回应留19集中验收。本记录不宣称整票宿主验收已完成。

## 可用行为

名称、标签、含义、替代文本、语气及使用语境参与共享确定性检索，处理Unicode、NFKC和中文分词；不适用语境只参与冲突降权，不单独产生正向候选。无匹配返回空数组，不用目录首项兜底。查询为1–240个Unicode code point且不能纯空白，默认最多3个候选，显式上限5个。

模型搜索只返回一份文字JSON，包含候选精确版本、完整名称/语义、随机选择凭据和政策。完整文本上限8192 UTF-8字节，超预算减少候选，保留完整avoid_when。合法最大字段样本的name+semantics为3936字节；5个匹配项在预算内保留1个，实际结果4299字节。候选不含视觉、blob或媒体路径，正常选择无需另调resolve。

服务端为返回候选生成24字节随机凭据，5分钟有效，绑定可信会话/回合与精确版本；未进入预算的项不保存凭据。发送复核当前可用性；同一已消费凭据优先查询原消息，不因之后过期再创建一次。

Codex/Claude共用面板通过受保护的GET /api/search调用相同检索逻辑，用户能搜索、看完整语义、查看精确版本及空状态，再向原绑定目标发送。dsh具有对应的原生Picker与人类search RPC，真实session经过校验；用户搜索不要求或伪造AI回合，不签发AI选择凭据，也不新增模型管理工具。

## 异步与兼容

共用面板离屏装配搜索卡片，图片完成后、最终一次更新DOM/状态/选择/预览前再次检查generation。反序图片请求检查确认新搜索完成后，旧结果不会混入。dsh取消旧搜索，并隔离新搜索、关闭及会话切换后的迟到结果。

Codex emit的既有display_markdown和dsh隐藏视觉元数据继续用于人类展示；候选无路径约束属于search。共享服务API和模型search返回形状保持兼容。旧测试以locale检索整库的假设改为使用已有use_when内容；locale不属于规定的检索字段，原精确版本/纯文字断言保留。

## 成本与待验范围

合同层正常AI表达是一次search加一次emit，无匹配是一次search后文字回应；实际模型也可能自行增加其他调用，需实测记录。面板搜索只产生本地请求。上述4299字节是实际结果序列化测量，不是模型Token估算。
